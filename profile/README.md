# Active Noise Control Research

This organization hosts open-source research and implementations related to active noise control.

## Public Research Areas

* Active noise control algorithms
* Distributed multichannel active noise control
* Simulation and implementation tools for ANC research

## Public Repositories

### [ANC_algorithm](https://github.com/ANC-Research/ANC_algorithm)

General implementations and demonstrations of active noise control algorithms.

### [ACDMCANC](https://github.com/ANC-Research/ACDMCANC)

Asynchronous communication distributed multichannel active noise control with event-triggered communication, WCFxLMS, and mixed weight-difference fusion.

## About

The repositories in this public profile contain openly available research code, documentation, and reproducible examples related to active noise control.
