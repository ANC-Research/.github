# Active Noise Control Research

Open-source research code and implementations for active noise control.

## Public Repositories

- [ANC_algorithm](https://github.com/ANC-Research/ANC_algorithm) — Reference ANC algorithms with MATLAB and Python implementations.
- [PriPathEst_MOVFxLMS_ANC](https://github.com/ANC-Research/PriPathEst_MOVFxLMS_ANC) — Output-constrained ANC using an improved MOV-FxLMS algorithm and a time-varying penalty factor.
- [ACDMCANC](https://github.com/ANC-Research/ACDMCANC) — Asynchronous-communication distributed multichannel ANC.
- [IC-DMCANC-CPA](https://github.com/ANC-Research/IC-DMCANC-CPA) — Distributed multichannel ANC with intermittent communication and coprocessor assistance.

See [anc-overview](https://github.com/ANC-Research/anc-overview) for the public project map.
